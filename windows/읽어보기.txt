레트로 에뮬레이터 (윈도우)
==========================

RetroEmu.exe 를 실행해요. 설치는 필요 없어요. 이 폴더째로 원하는 곳에 두면 돼요.

롬 넣기
- 창에 롬 파일을 끌어다 놓거나, 오른쪽 위 "롬 추가"(Ctrl+O)를 눌러요.
- 롬은 들어 있지 않아요. 가지고 있는 롬을 넣어요.
- 되는 기종: 패미컴, 게임보이, 게임보이 컬러, 게임보이 어드밴스, 슈퍼패미컴, 메가드라이브, 플레이스테이션

게임 목록
- 방향키로 고르고 Enter 로 시작, 마우스로 눌러도 돼요.
- 오른쪽 클릭 또는 Delete: 목록에서 지우기(저장은 남아요)

게임 중 키
  방향키        방향
  Z / X         B / A
  A / S         Y / X
  Q / W         L / R
  E / R         L2 / R2
  Enter         스타트
  Backspace, Tab 셀렉트
  F1 / F2       저장 / 불러오기 (마지막에 고른 슬롯)
  F3            저장 목록
  F11, Alt+Enter 전체 화면
  Esc           나가기

저장
- 게임마다 슬롯 6칸 + 자동 저장 1칸. 칸마다 화면과 시각이 남아요.
- 5초 넘게 하고 나가면 자동 저장되고, 다음에 켜면 저장 목록부터 떠요.
- 저장 목록: 방향키로 고르고 Enter 불러오기, S 저장, Delete 지우기, Esc 닫기.

게임패드
- 엑스박스, 플스, 스위치 프로 패드 등 연결하면 바로 써져요.
- 버튼은 위치 기준이에요(아래=B, 오른쪽=A, 왼쪽=Y, 위=X).
- 셀렉트+스타트(또는 가운데 홈 버튼): 저장 목록
- 메뉴에서는 십자키/스틱으로 고르고 아래 버튼 = 확인, 오른쪽 버튼 = 뒤로, 왼쪽 버튼 = 저장, 위 버튼 = 지우기

파일 위치
- 롬과 저장: %APPDATA%\RetroEmu\ (roms, saves, system)
- 플레이스테이션 BIOS(선택): %APPDATA%\RetroEmu\system\scph5501.bin

출처
- 에뮬레이션: libretro 코어(FCEUmm, mGBA, Snes9x, Genesis Plus GX, PCSX ReARMed). Snes9x 와 Genesis Plus GX 는 비상업적 사용만 허락해요.
- 화면: SDL2, SDL2_ttf (zlib), 글꼴 Pretendard (SIL OFL), 게임기 사진(퍼블릭 도메인). licenses 폴더를 보세요.
